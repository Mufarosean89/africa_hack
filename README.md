# MajiWatch

MajiWatch is a lightweight community water-point status finder. People can search or filter nearby points, optionally sort by device location, and share a status update with a short note.

## Run the demo

Serve this folder over localhost or HTTPS (for example, `python -m http.server 8000`) and open it in a browser. The app has no build step or runtime dependencies. After the first visit, its app shell is cached for offline use; reports are saved in that browser's local storage.

All locations and starting reports are sample data, not live or verified service information. Updates in this prototype stay on the device and are not shared with other people. Do not rely on the demo to plan a trip.
